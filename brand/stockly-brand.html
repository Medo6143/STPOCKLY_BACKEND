A paper invoice becomes clean stock data

The mark is the product in one picture: a supplier receipt whose printed lines turn into data cells. The splash plays that moment once while the app checks the saved login, then hands over to the home screen.

Flutter implementation
  • flutter_native_splash draws the first frame (background + static mark) so there is no white flash on Android or iOS.
  • The animated splash is a Flutter route built with flutter_animate, same timings as above. It runs in parallel with the token refresh and leaves when both finish, minimum 1.8 s, maximum 3 s.
  • When the system “reduce motion” setting is on, the final frame shows without animation.
  • Colors come from ThemeExtension tokens, text from app_ar.arb / app_en.arb. Layout uses EdgeInsetsDirectional so RTL mirrors correctly.
